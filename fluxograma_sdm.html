Guia de Comunicação

  • Frontend ➔ Backend: Comunicação via API RESTful (v1) utilizando Inertia.js para uma experiência de SPA.
  • Auth Middleware: Centraliza a segurança, verificando permissões granulares no módulo de Identity.
  • Inter-Módulos: O sistema utiliza eventos e relações de banco de dados para manter a consistência entre Vendas, Financeiro e Estoque.
  • ETL: Ponte vital que traz os dados do sistema legado para a arquitetura moderna de forma estruturada.
